# E-Commerce Revenue & Customer Analytics Project

## Project Overview

This project is an end-to-end Data Analytics project built using the Superstore retail dataset. The objective is to analyze sales performance, profitability, customer behavior, product performance, and regional trends to generate actionable business insights.

The project demonstrates the complete analytics workflow including:

* Data Cleaning and Transformation using Python
* Exploratory Data Analysis (EDA)
* Business Analysis using SQL
* Interactive Dashboard Development using Power BI
* Business Insight Generation and Reporting

## Key Business Insights

### Category Insights

* Technology generated the highest profit.
* Furniture generated high sales but low profit margins.

### Regional Insights

* West region achieved the highest profitability.
* Central region underperformed compared to other regions.

### Product Insights

* Copiers and Phones were top profit contributors.
* Tables and Bookcases generated losses.

### Discount Insights

* Higher discount levels negatively impacted profitability.
* Large discounts frequently resulted in losses.

### Customer Insights

* A small group of customers contributed a significant share of revenue.
* Revenue distribution showed customer concentration risk.

### Time Trend Insights

* Sales peaked during November and December.
* Strong year-over-year growth trend observed.

---

## Project Outcome

This project identified profitability drivers, loss-making products, regional performance gaps, customer concentration risks, and seasonal sales trends. The findings can support better pricing, discount management, and strategic business decisions.
